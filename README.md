# Rive Or — démo GitHub Pages

1. Ajouter vos JPG dans `assets/` sous les noms `hero.jpg`, `collection-1.jpg`, `collection-2.jpg`, `collection-3.jpg`, `atelier.jpg`, `detail.jpg`. Sans image, un emplacement s'affiche.
2. Remplacer dans les trois fichiers HTML `VOTRE_EMAIL`, `VOTRE_NUMERO` et `EMAIL_BIJOUTERIE`.
3. Envoyer les fichiers à la racine d'un dépôt GitHub, puis Settings > Pages > Deploy from a branch > main > /(root).
4. Le logo fourni est déjà dans `assets/logo.jpg`.

Maquette non officielle. Les textes ne sont pas des affirmations vérifiées sur la maison. Aucun e-commerce, analytics ou CMP n'est installé. Les polices sont chargées depuis Google Fonts.
